# OTTO B1 — Preview 1

Fresh owner-walkthrough preview built from OTTO B1 Technical Spec v1.0.

This branch is intentionally separate from `main` and is not production.

## Walkthrough

Use the ✓ button in the app to follow the owner-review scenario. To inspect the complete error-repair branch, intentionally answer the first daily Lesen task incorrectly.

## Preview boundaries

- Small representative original_aligned content set, not the final content bank.
- Hören uses browser German speech synthesis only as a preview audio source.
- Schreiben feedback is deterministic structural preview feedback, not an official Goethe score.
- Sprechen can capture microphone evidence but does not claim pronunciation scoring.
- Exam-mode is a short proof-of-concept, not a full mock exam.
- Otto Personal is a UI/context shell; online AI is not connected in this preview.
